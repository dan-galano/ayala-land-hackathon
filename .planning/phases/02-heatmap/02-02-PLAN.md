    Requirements (locked from CONTEXT.md + research patterns):

    **Grid structure:**
    - 25 rows (Floor 26 at top, Floor 2 at bottom — descending order so building reads bottom-to-top)
    - 20 columns (unit positions 1-20 per floor)
    - Cell size: 28px tall (row height), width fills column (grid auto-distributes)
    - Gap: gap-[2px] between cells
    - Grid container uses `grid grid-cols-20 gap-[2px]` with `style={{ gridTemplateRows: 'repeat(25, 28px)' }}`
    - If `grid-cols-20` produces no CSS (Tailwind v3 fallback risk), use `style={{ gridTemplateColumns: 'repeat(20, minmax(0, 1fr))' }}` instead — check at dev time and use inline style as escape hatch

    **Floor labels (left axis):**
    - Flex column of labels: F26, F25, ..., F2 (top to bottom)
    - Each label: h-7 (28px) w-8 text-xs text-slate-400 text-right pr-1
    - Same gap-[2px] as grid to stay aligned with rows
    - CRITICAL: floor labels must be aligned to their grid rows. Use the same row height (28px / h-7) and gap (gap-[2px]) on the label column as the grid.

    **Building header:**
    - Above the grid: `<h1 className="text-white text-2xl font-bold mb-4">Avida Towers Vita</h1>`

    **State management:**
    - `useState<Unit | null>(null)` for selectedUnit
    - `useMemo` to sort units into grid order: group by floor, sort floor 26 down to 2, each row sorted position 1-20

    **Component composition:**
    - Render floor labels div + grid div side by side (flex gap-4 container)
    - Grid renders UnitCell per unit via `grid.flatMap(row => row.units.map(unit => ...))`
    - Pass `isSelected={selectedUnit?.id === unit.id}` and `onClick={() => setSelectedUnit(unit)}` to each UnitCell
    - Also render `<UnitDetailPanel unit={selectedUnit} onClose={() => setSelectedUnit(null)} />` (import from UnitDetailPanel — this component doesn't exist yet, but add the import and usage as a placeholder. The TypeScript error for missing module is expected and will be resolved in plan 03.)

    **IMPORTANT — React.memo and onClick stability:**
    Per research pitfall 2: `onClick={() => setSelectedUnit(unit)}` creates a new function per render but since `unit` objects in the useMemo grid array are stable references (only recomputed when `units` prop changes, which it never does), React.memo's shallow comparison will still see a changed `onClick` function on every parent render triggered by selectedUnit state changes. To avoid this: use `useCallback` with unit.id as dependency, OR accept that only 2 cells re-render on each click (the old selected + new selected) since all other UnitCells receive the same unit prop and isSelected=false. The `isSelected` prop changes for exactly 2 cells per click, so React.memo correctly prevents re-rendering the other 498 cells. The onClick function reference changes for all 500, but the isSelected change is the actual render trigger.

    Props interface:
    ```typescript
    interface Props {
      units: Unit[]
    }
    ```

    Export as named export `HeatmapGrid`.
