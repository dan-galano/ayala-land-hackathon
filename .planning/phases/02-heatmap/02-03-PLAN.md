  <name>Task 2: Create app/page.tsx — Server Component fetching /api/units and rendering HeatmapGrid</name>
  <files>
    client/app/page.tsx
  </files>
  <action>
    Replace the default Next.js starter `client/app/page.tsx` with the dashboard page.

    This is a Server Component (async function, no "use client"). It fetches unit data from the Express API at server-render time (not in the browser) — this bypasses CORS because the request originates from the Next.js Node.js process, not the browser.

    Implementation:
    ```tsx
    import { HeatmapGrid } from '@/components/HeatmapGrid'
    import type { Unit } from '@/lib/types'

    export default async function Page() {
      let units: Unit[] = []

      try {
        const res = await fetch('http://localhost:3001/api/units', {
          cache: 'force-cache',
        })
        if (!res.ok) throw new Error(`API error: ${res.status}`)
        units = await res.json()
      } catch (err) {
        console.error('Failed to fetch units from Express API:', err)
        // Render empty grid gracefully — don't crash the page
      }

      return (
        <main className="p-6">
          <HeatmapGrid units={units} />
        </main>
      )
    }
    ```

    Notes:
    - The `<main>` element intentionally has NO background color — the root layout (layout.tsx) provides `bg-slate-900` on the body. Do not duplicate the dark background here.
    - The `cache: 'force-cache'` tells Next.js to cache the response — seeded data never changes, so this is correct and avoids redundant API calls during development.
    - The try/catch renders an empty grid on API failure rather than crashing. This is intentional defensive coding.
    - `HeatmapGrid` handles its own header rendering ("Ayala Land" h1) — do NOT add a duplicate header in page.tsx.
    - The Express server must be running on port 3001 for the fetch to succeed. If the API is down, the page renders with an empty grid (graceful degradation).

    After creating page.tsx, start both servers and verify the dashboard loads:
