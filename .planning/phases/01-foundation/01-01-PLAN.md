Create `server/src/classifier.ts` exporting a single pure function:
```typescript
export function classifyUnit(
  currentKwh: number,
  baselineKwh: number,
  isOccupied: boolean,
  isVampireFlagged: boolean
): UnitStatus {
  const ratio = currentKwh / baselineKwh;
  if (isVampireFlagged && !isOccupied && ratio > 0.6) return 'vampire';
  if (ratio > 1.2) return 'critical';
  if (ratio > 1.0) return 'warning';
  if (ratio > 0.8) return 'elevated';
  return 'normal';
}
```
No state, no imports of mutable data, no side effects. Import UnitStatus from types.ts.

Create `server/src/seed.ts`:
1. Import faker from '@faker-js/faker'. Call `faker.seed(42)` as the VERY FIRST LINE before any other code (not inside a function — at module level, before imports' side effects can fire).
2. Generate units in a loop: floors 2–26 (inclusive), positions 1–20 per floor = 500 units exactly.
   - Unit ID format: `${String(floor).padStart(2,'0')}${String(pos).padStart(2,'0')}` — e.g. floor 2 pos 3 = "0203"
   - Unit type via `faker.helpers.weightedArrayElement([{weight:40,value:'studio'},{weight:40,value:'1BR'},{weight:20,value:'2BR'}])`
   - currentKwh via `faker.number.float({min: CONSUMPTION_RANGES[type].min, max: CONSUMPTION_RANGES[type].max, fractionDigits: 1})`
   - Anomaly flagging: `const roll = faker.number.float({min:0, max:1, fractionDigits:4})`. If `roll < 0.04` → isVampireFlagged=true, isOccupied=false, anomalyType='vampire'. Else if `roll > 0.985` → isSpiked=true, anomalyType='spike'. Else anomalyType=null. (Hero overrides applied afterward — these flags are just for non-hero units.)
   - Call classifyUnit() to get status
   - Compute co2e = parseFloat((currentKwh * GRID_EMISSION_FACTOR).toFixed(3))
   - Compute savingsPercent = parseFloat(((baselineKwh - currentKwh) / baselineKwh * 100).toFixed(1))
3. Apply hero unit overrides AFTER the loop (as a map pass — do NOT special-case inside the loop or RNG position shifts):
   - '1203': currentKwh=1500 (BASELINE_KWH['2BR']*3), type='2BR', anomalyType='spike', status='critical', isOccupied=true. Recompute co2e and savingsPercent from overridden currentKwh.
   - '0815': currentKwh=255 (BASELINE_KWH['1BR']*0.85), type='1BR', anomalyType='vampire', status='vampire', isOccupied=false. Recompute co2e and savingsPercent.
   - '2510': currentKwh=175 (BASELINE_KWH['2BR']*0.35), type='2BR', anomalyType=null, status='normal', isOccupied=true. Recompute co2e and savingsPercent.
4. Export `export const ALL_UNITS: Unit[] = generateUnits();` at module level.
5. Export `export const ANOMALIES: Unit[] = ALL_UNITS.filter(u => u.anomalyType !== null);`

CRITICAL: Do NOT call faker.seed() inside generateUnits(). Call it at module level before the function definition.
CRITICAL: Use ONLY faker.* RNG calls for randomness — do not mix in Math.random().
